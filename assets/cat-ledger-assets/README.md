## 四、使用建议

1. **图标类（icon-）**：Web 中建议以 PNG 透明背景使用；当前为纯白底，可在前端用 `mix-blend-mode` 或抠图工具去底后嵌入按钮 / 菜单。
2. **插画 / Banner（illust-、banner-）**：图片内部已预留空白，标题、按钮、文案全部由前端代码叠加，**不要在图片内生成文字**，避免小尺寸出现乱码。
3. **配色一致性**：整套沿用薄荷绿、奶油白、淡紫、冰蓝、暖橙；主色以 Logo 的薄荷 + 鹅黄为准，辅助色按模块轮换。
4. **尺寸适配**：
   - 1:1 图标用于菜单、按钮、卡片角标；
   - 16:9 用于 Hero、功能板块、空状态；
   - 超宽幅用于落地页通栏，需注意在窄屏下裁切居中。
5. **负面约束（复用于后续重绘）**：
   `text, letters, words, numbers, watermark, logo, app icon tile, rounded square background, square container, badge, border, frame, UI card, phone mockup, complex background, cluttered, multiple cats, realistic fur, realistic eyes, busy details, low contrast, blurry, cropped, tiny details`
6. 若重绘仍带圆角底板，在提示词开头追加：`standalone transparent icon object, no background tile`。
